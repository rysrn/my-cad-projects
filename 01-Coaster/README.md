# Project 01: Coaster

A 3D model of a premium desk coaster, reverse-engineered using precise millimeter measurements from a physical object over a **1.5-hour design session**.

## 📐 Design Specifications & Materials

This project replicates the multi-layered structure of a real-world utility coaster:

* **Outer Rim / Frame:** Mahogany Wood (applied with clean vertical grain orientation)
* **Inlaid Base:** A 1mm deep recessed circular cavity, modeled with Cherry Wood to establish the structural underlying surface.
* **Base Protection:** 4 precise, evenly spaced 1mm extruded rubber cylinders placed on the underside to prevent slipping and protect desk surfaces.

## 🛠️ Skills Mastered

* **Physical Reverse Engineering:** Utilizing technical measurements to map an existing physical desktop item into digital 3D space with a 99% accuracy rate.
* **Multi-Material Separation:** Splitting faces and bodies to isolate differing aesthetics (wood fibers vs. matte rubber textures).
* **Ray-Traced Rendering:** Transitioning from the canvas grid to the Render Studio to apply ground plane shadows and environmental lighting.
